# App icon

An abstract open ring and directional arrow, with no car depiction, manufacturer
logo, product photography or recognizable model styling. The manufacturer's
vehicles and branding must not be used in app icon artwork.

Generated with the built-in `image_gen` tool in **generation** mode, with a
transparent background. `source.png` is the original output. Run
`bash packaging/build-icons.sh` on macOS to resize it and pack the native formats:

- `wltoys-drive.png`: Linux desktop shortcut
- `wltoys-drive.icns`: both macOS app bundles
- `wltoys-drive.ico`: Windows executable, player window and taskbar

## Final generation prompt

Use case: logo-brand. Asset type: native desktop application icon for an independent wireless driving and FPV video utility. Create one original, minimal abstract emblem, with no physical products or vehicles. A bold off-white open circular ring with a deliberate gap at the upper right; within it, one simple vivid red directional triangle points diagonally toward that opening, suggesting control, forward motion and transmitted video. Treat this as one coherent graphic mark, not a collection of symbols. Center it on a smooth near-black charcoal rounded-square tile with generous margins. Clean flat geometric design, precise balanced spacing, strong silhouette, excellent readability at 16 and 32 pixels. Subtle background shading is acceptable, but the emblem is flat and crisp. Square composition, transparent outside the rounded tile. No text, letters, numbers, car, wheels, buggy, camera hardware, model-car depiction, manufacturer logos, existing brand marks, recognizable product designs, chrome, bevels, photorealism, 3D objects, decorative details, extra icons, watermark or mockup.
