# WLtoys Drive app icon

Generated with the built-in `image_gen` tool in **generation** mode, with a
transparent background. The original output is `source.png`; conversion only
resizes it and packs native containers. Run `bash packaging/build-icons.sh` on
macOS to regenerate the checked-in PNG, ICNS and seven-size ICO.

The PNG is the Linux launcher icon. Both macOS app bundles use the ICNS. The
Windows launcher embeds the ICO, and the keyboard helper applies it to the
bundled player's window and taskbar.

## Final generation prompt

Create a single polished desktop application icon for “WLtoys Drive”, an app for
driving a small RC car with a live FPV camera. Square 1024 by 1024 composition. A
compact white toy racing buggy viewed from the front at a slight three-quarter
angle, chunky black wheels, small vivid red accents, and a prominent glossy dark
camera lens mounted above the hood so the car-and-camera idea reads instantly.
Simple bold silhouette, very few details, readable at 32 pixels. Tasteful
dimensional illustration with crisp clean edges and soft controlled lighting,
restrained black, white, charcoal, and racing red palette. Place the car on a deep
charcoal rounded-square tile, with generous safe margins and subtle depth.
Transparent background outside the rounded square. One centered icon only. No
text, no letters, no numbers, no logos, no watermark, no extra UI, no surrounding
mockup.
